Racing Setup Hub – kompletter GT7-Herstellerkatalog

Enthalten: 575 Fahrzeuge in 76 Herstellerdateien.

Einbau:
1. ZIP entpacken.
2. Die Ordner data und js in deinen Projektordner kopieren.
3. Dateien/Ordner zusammenführen und js/config.js ersetzen.
4. Alte Dateien unter data/gt7/gr3 können bleiben; sie werden von der neuen config.js nicht mehr geladen.
5. Live Server neu starten und Strg + F5 drücken.

Hinweise:
- Vorhandene persönliche Setups wurden, soweit sie eindeutig zugeordnet werden konnten, übernommen.
- Fahrzeuge ohne Setup besitzen zunächst ein leeres setups-Array.
- Einige Sonder-/Bonusfahrzeuge sind in der Quelldatei enthalten; deshalb umfasst das Paket 575 Datensätze.
